# ADR 0005: Slice 1 scope, defaults, and unresolved owner decisions

- Status: Accepted
- Date: 2026-08-04

## Context

The implementation plan explicitly starts with project foundation. Several product-owner choices are not required to prove this slice.

## Decision

Slice 1 delivers a deployable bilingual application shell, design tokens/primitives, CI, complete initial schema/migration, repository/unit-of-work contracts, PostgreSQL composition, object-storage contract/adapter, configuration safeguards, seed foundation, and tests.

Assumptions:

- Node 22 and npm are the baseline toolchain.
- `vi` is default; only `vi` and `en` are valid.
- PostgreSQL is the only durable store in all environments.
- S3-compatible private storage is the initial media implementation; no vendor is selected permanently.
- UUIDs are generated by PostgreSQL or application code; timestamps are UTC.
- JSONB is used only for bounded immutable snapshots/config/audit summaries, never as a filesystem database substitute.
- Step 1 does not expose question/attempt APIs, so no answer-bearing response exists yet. The disclosure policy and DTO boundary are established now and tested when those endpoints arrive.
- Accessibility baseline is semantic HTML, visible focus, reduced-motion support, minimum 360px layout, and WCAG 2.1 AA-oriented contrast; automated and manual audits continue in every UI slice.

Unresolved without blocking development:

- The legal author/owner and license are not inferred. `package.json` remains private/UNLICENSED and public release is blocked until the owner supplies them.
- Brand assets, public domain, concrete managed providers, retention policy, privacy terms, and account-deletion policy remain owner decisions.

## Consequences

Completing slice 1 does not claim the MVP is feature-complete. Later slices must keep migrations and acceptance tests adjacent to each delivered capability.
